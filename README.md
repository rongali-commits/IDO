# Noerong

Noerong is a product studio focused on practical SaaS products for small teams, agencies, and growing businesses.

This repository contains the production portfolio at [noerong.com](https://noerong.com), including product showcases and the preserved Noerong essay archive.

## Current product

- **LeadDesk AI** — a focused lead qualification and follow-up workspace for service businesses.

## Stack

- Next.js and React
- TypeScript
- OpenAI Sites hosting

## Local development

```bash
npm install
npm run dev
```

Run validation before publishing:

```bash
npm run lint
npm run build
```

## Deployment

Production is deployed through OpenAI Sites. Domain DNS and email routing are managed separately through Hostinger.

The writing archive remains available under `/essays`.
